# Луна 🎹

Музична гра на пам'ять: слухаєш випадкову мелодію і повторюєш її на піаніно.
Один файл, без збірки — Tailwind підключений через CDN, звук генерується Web Audio API прямо в браузері.

## Як грати

1. Відкрий `index.html` у браузері.
2. Натисни **«Слухати мелодію»**.
3. Повтори почуту послідовність нот, клікаючи по клавішах піаніно.
4. Правильна мелодія → рахунок і серія ростуть. Помилка → серія скидається, можна прослухати ще раз.

## Налаштування (кнопка ⚙)

- **Нот у мелодії** — довжина послідовності (3–16).
- **Клавіш на піаніно** — скільки білих клавіш генерується (5–18), чорні додаються автоматично за стандартним звукорядом.
- **Пауза між нотами** — інтервал відтворення мелодії, у мс (200–1200).

Налаштування зберігаються в `localStorage` браузера.

## Запуск локально

Файл не потребує сервера — можна відкрити напряму подвійним кліком.
Якщо браузер блокує щось через `file://`, підніми простий сервер:

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000
```

## Деплой на GitHub Pages

```bash
git init
git add .
git commit -m "Луна: гра на музичну пам'ять"
git branch -M main
git remote add origin <URL_твого_репозиторію>
git push -u origin main
```

Далі в репозиторії: **Settings → Pages → Source: main branch, / (root)** — і гра буде доступна за адресою
`https://<username>.github.io/<repo>/`.

## Стек

- HTML + Tailwind CSS (CDN, без білд-кроку)
- Vanilla JavaScript
- Web Audio API для звуку (осцилятори, без аудіофайлів)

Ніякого збору даних, нічого не відправляється на сервер — усе працює локально в браузері.
